# module-grade-evaluator
Helps to add obtained/predicted grades and goals for each module and as a whole year. 

Shows average required scores to achieve a target of 70%. Allows analysis of predicted grade contribution to final year score

## Future Features
- What-if / scenario sliders: drag predicted scores per module and see live final grade impact
- Export to PDF / CSV: generate a summary report for tutors or personal records
- Historical grade timeline: plot grade trajectory as assessments are entered over time
- Task due dates & deadline panel: add dates to tasks and show upcoming deadlines sorted by urgency
- Module tags / category filter: tag modules (Core, Lab, Elective) and filter the grid by category
- Dark mode / theme switcher: persist a chosen PySimpleGUI theme across sessions
- Auto-backup + undo: keep a timestamped backup of grades.json before each save

## dependancies
